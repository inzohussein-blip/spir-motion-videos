# 08-workflows

خطوات عمل موثّقة من الفكرة إلى التصدير.

## مثال: فيديو Reel بالذكاء الاصطناعي
1. **الفكرة والسكربت:** Claude ← `06-ai-prompts/scripts/`
2. **الستوري بورد:** تقسيم السكربت إلى مشاهد
3. **توليد المرئيات:** صور ← فيديو (`06-ai-prompts/image/` و`video/`)
4. **التعليق الصوتي:** ElevenLabs ← `04-audio/voiceover/`
5. **المونتاج والموشن:** قالب من `05-video-templates/` + حركات من `01-motion-templates/`
6. **الصوت:** موسيقى ومؤثرات من `04-audio/`
7. **التصدير:** 1080x1920، 30fps، H.264
