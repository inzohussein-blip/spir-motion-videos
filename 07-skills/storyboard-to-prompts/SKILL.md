# storyboard-to-prompts

## الهدف
لكل مشهد: برومبت صورة (Keyframe) + برومبت حركة (Image-to-Video)، بأسلوب بصري موحّد.

## المدخلات
- جدول المشاهد (من `video-script-writer` أو من المستخدم).
- أداة الصور (Midjourney / Flux / GPT Image ...) وأداة الفيديو (Veo / Kling / Runway ...).
- المقاس (9:16 أو 16:9).

## الخطوات
1. **بطاقة الأسلوب (Style Bible):** فقرة إنجليزية واحدة تُلصق في كل برومبت:
   نوع اللقطة السينمائية، الإضاءة، لوحة الألوان، العدسة، الحبيبات (grain)، المزاج.
2. **بطاقة الشخصية:** وصف ثابت ودقيق لكل شخصية (العمر، الملابس، الشعر، الملامح) يتكرر حرفياً.
   استخدم صورة مرجعية (character reference) إن كانت الأداة تدعمها.
3. **برومبت الصورة لكل مشهد** بالترتيب:
   `[الموضوع والفعل] + [المكان] + [تكوين اللقطة] + [Style Bible] + [المقاس]`
4. **برومبت الحركة لكل مشهد:** يصف الحركة فقط، لا يعيد وصف الصورة:
   `[حركة الكاميرا] + [حركة العنصر] + [السرعة/المزاج]` — مثل: `slow dolly in, steam rising, subtle hand movement`.
5. **النصوص:** لا تضع النص العربي داخل الصورة المولّدة (غالباً يخرج مشوّهاً)؛ أضفه في المونتاج.
6. **الاستمرارية:** راجع أن الإضاءة والملابس والمكان متسقة بين المشاهد المتتالية.

## المخرجات
```markdown
## Style Bible
...

## الشخصيات
- **A:** ...

## المشاهد
### مشهد 1 (0:00–0:03)
- **Image prompt:** ...
- **Video prompt:** ...
- **Negative / تجنّب:** text, watermark, extra fingers, distorted face
- **ملاحظات المونتاج:** النص "..." يظهر بحركة pop-in
```

## نصائح حسب الأداة
| الأداة | نصيحة |
|---|---|
| Midjourney | `--ar 9:16 --style raw`، واستخدم `--cref` / `--sref` للثبات |
| Flux | جمل وصفية طبيعية، تفاصيل الإضاءة مهمة |
| Veo / Kling | مدة 5–8 ث للمشهد، حركة كاميرا واحدة واضحة لكل لقطة |
| Runway | ابدأ من صورة عالية الجودة، وقلّل الحركات المتزامنة |

احفظ البرومبتات الناجحة في `06-ai-prompts/` باستخدام `_templates/prompt-template.md`.
