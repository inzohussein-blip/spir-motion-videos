# video-script-writer

## الهدف
تحويل فكرة أو منتج أو رسالة إلى سكربت فيديو جاهز للإنتاج، يُستخدم مباشرة في
الستوري بورد وتوليد المرئيات والتعليق الصوتي.

## قبل البدء
حدّد الشركة واقرأ `03-design-assets/brand-kits/<id>/brand.json`: حقل `voice` يحدد اللهجة والنبرة وما يُتجنّب، و`cta` الدعوة الافتراضية. ما في الهوية يتقدّم على الافتراضيات أدناه.

## المدخلات (اسأل عن الناقص فقط)
| المدخل | الافتراضي |
|---|---|
| الشركة (`brandId`) | — (مطلوب) |
| الموضوع / المنتج | — (مطلوب) |
| الجمهور المستهدف | عام |
| المنصة والمقاس | Reels/TikTok — 9:16 |
| المدة | 30 ثانية |
| اللغة واللهجة | عربي فصيح مبسّط |
| النبرة | حماسية وواضحة |
| الدعوة للإجراء (CTA) | متابعة الحساب |

## الخطوات
1. **الخطّاف (Hook):** أول 3 ثوانٍ: سؤال، رقم صادم، أو وعد بنتيجة. اكتب 3 بدائل واختر الأقوى.
2. **البنية:** Hook ← المشكلة ← الحل/القيمة ← الدليل ← CTA.
3. **التقسيم:** مشهد كل 2–4 ثوانٍ للفيديو القصير (تغيير بصري متكرر يحافظ على الانتباه).
4. **سرعة الكلام:** ~2.5 كلمة/ثانية بالعربي. تأكد أن عدد كلمات كل مشهد يناسب مدته.
5. **النص على الشاشة:** 3–6 كلمات كحد أقصى لكل مشهد، ولا يكرر التعليق الصوتي حرفياً.
6. **المرئيات:** صف كل مشهد بوضوح (اللقطة، الحركة، الإضاءة) ليتحوّل لاحقاً إلى برومبت.
7. **الصوت:** اقترح نوع الموسيقى ومؤثرات عند الانتقالات (whoosh / impact / riser).

## قواعد الجودة
- لا مقدمات مملة؛ القيمة تبدأ من الثانية الأولى.
- كل مشهد يخدم الرسالة، احذف ما لا يضيف.
- مجموع التوقيتات = المدة المطلوبة بالضبط.
- احفظ السكربت النهائي في `09-projects/<client-id>/<YYYY-MM-DD>-<slug>/script.md`.
- عمود "النص على الشاشة" يُنقل مباشرة إلى `scenes` في قالب Remotion (`text` + `accent`).
